## About

I am an independent, self-taught software developer with a broad foundation across the full web stack — from building responsive, accessible frontends to designing and maintaining backend services and databases. My work is guided by a security-first mindset, reflecting a deep interest in cybersecurity principles and their practical application in software development.

I am actively seeking opportunities to collaborate on meaningful projects, particularly in the areas of full-stack web development, open-source tooling, and cybersecurity research.

**Areas of focus:**
- Full-stack web application development (frontend + backend + databases)
- Cybersecurity concepts, secure coding practices, and vulnerability research
- Cross-platform mobile development with Flutter and Kotlin
- Embedded systems and hardware interfacing via Arduino
